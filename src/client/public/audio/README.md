# Your own tavern recordings (optional)

The fire, the tavern crowd and the music are generated live in the browser. To use real recordings
instead, put audio files here with these names (any of .ogg, .mp3 or .wav) and rebuild (`npm run build`):

- `fire.ogg` — a looping fireplace
- `tavern.ogg` — looping tavern crowd / background noise
- `music.ogg` — looping background music

Each one you add replaces only that part. Only use recordings you're allowed to use
(for example CC0 / public-domain sounds); don't rip audio from YouTube videos.
